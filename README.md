# Learning-Journey-TypeScript

This repository is part of my **Learning Journey series**, documenting my exploration of **TypeScript** and type-safe development for modern web applications.

Here, I explore TypeScript fundamentals, type annotations, inference, interfaces, type aliases, unions, type narrowing, generics, API typing, and **React with TypeScript** through small hands-on examples and experiments.

## Note

This repository documents my **hands-on learning and experimentation with TypeScript**.

The examples are intentionally kept small and focused so that each implementation reinforces a specific TypeScript or React + TypeScript concept, while maintaining clean repository structure, documentation, and Git history.

## React + TypeScript Examples

### Card Component

A typed React component demonstrating **props, `PropsWithChildren`, `ReactNode`**, optional props, and interface extension.

### Order Form

A typed React form demonstrating **callback props, `useState`, React event types**, controlled inputs, number conversion, and form submission.

### Counter

A simple React component demonstrating **typed state** and functional state updates with `setState`.

### Tea Card

A component demonstrating **typed props, optional properties, destructuring, and conditional rendering**.

### Tea List

A list component demonstrating **typed arrays, reusable components, `.map()`, and React keys**.

### Generic `useFetch` Hook

A custom hook demonstrating **TypeScript generics** and how a reusable React hook can preserve the type of fetched data.
